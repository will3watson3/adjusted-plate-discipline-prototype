# Frozen XGBoost swing-path comparison

November 16, 2026. Scope: complete the four-branch swing path using the already frozen contact XGBoost plus new BIP-given-contact, caught-tip-given-non-BIP-contact and BIP-value models. No take-model change or activation.

Each new stage receives exactly its updated-history population GAM's RHS predictor variables, transformations, factor information and missingness indicators. No identities, source zone, additional predictors, current-pitch exit velocity/launch angle or outcomes enter a predictor. Contact and historical power profiles use completed season y−1. Factor one-hot encoding conveys the same information as GAM factors. BIP value predicts runs_on_play + frozen RE288_after; it is not a probability.

Development: 2022 training, 2023 validation, preprocessing fitted on the 2022 stage cohort only. BIP-value development targets use the saved 2022-only RE288 table; the 2023 validation outcomes cannot influence that table. Final models and targets reuse the same frozen 2022–23 RE288 and the same verified training cohorts as their GAMs. Preserve post-play identity, event, run and runner-conservation audits and exceptional-event exclusions.

For each stage, compare depths 3/4/5; learning rate .05; min_child_weight 50; lambda 10; alpha 1; subsample .8; colsample_bytree .9; max_bin 256; CPU/two threads; seed 20261116. Maximum 1200 rounds, patience 60. BIP/tip use unweighted binary logistic/log loss; value uses a positive Poisson-mean objective with RMSE selection (nonnegative continuous runs+RE targets, not an assertion of literal Poisson-distributed counts). Refit the minimum-validation-loss candidate on 2022–23 for its selected rounds. Exact ties favor lower depth. Record capped candidates. No 2024/2025 tuning or recalibration. All stages must freeze before evaluation. The previously selected contact model is reused without further search.
