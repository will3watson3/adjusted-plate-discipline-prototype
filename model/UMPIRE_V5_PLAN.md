# Umpire identity and incremental predictive-value experiment

Goal: determine whether reliable game-level home-plate umpire assignments are available and whether historical umpire tendencies improve later-game ordinary called-strike probabilities beyond the current v4 catcher-framing plus weekly calibration benchmark. Preserve every frozen v1-v4 input/artifact. No half-season stability gate.

Data contract: acquire public MLB boxscore `officials` using game_pk from existing audited 2022-2025 cohorts (include 2023 for history; 2022 availability audit). Store raw minimal JSON, URL/hash, explicit missing/multiple-home-plate status. Join one row per game without changing pitch order or support masks. A boxscore assignment is game-level; rare mid-game umpire replacements may not be represented. Do not assert pitch-level umpire identity independently verified. Missing/ambiguous assignments receive average prior effects; report their coverage rather than dropping pitches silently.

Models fixed before candidate outcomes are analyzed: (1) current v4 benchmark, (2) a catcher-only model with a shared fixed coarse-region correction and no umpire identity, (3) prior-season jointly estimated catcher and umpire Normal random intercepts plus that same shared-region correction, (4) the same plus an umpire-by-coarse-region Normal random effect. The shared regional control isolates genuine umpire-identity information from generic location calibration. This control was specified during data acquisition before any candidate predictive comparison; the catcher-only reproduction check does not select a model. Regions are the existing above/below/side/inside definition. Joint estimation replaces the old catcher effect completely, retaining the frozen location/context GAM with its catcher smooth excluded. No official framing-run total is added as a second weight. Hyperparameters and latent effects use only the previous season. Predict by integrating joint posterior latent variance; unobserved groups receive population priors. Fit a catcher-only control to verify reproduction of the v2 framing mechanism.

For 2024 prediction, use the frozen 2022-2023 called-strike base and 2023 random-effect evidence. Recompute 2023 no-catcher offsets with that base (the cached 2023 development predictions used a 2022-only base and cannot be substituted). For 2025 prediction, same frozen base and 2024 random-effect evidence. The base is trained before the prediction year; overlap of the 2023 random-effects evidence with base fitting is historical, not independent evaluation. Every model gets its own otherwise identical weekly expanding-season intercept calibration using only earlier current-year games; minimum 2,000 takes, same v4 numerical stabilization and schedule. This tests incremental umpire information rather than merely fixing global drift.

Historical selection: 2024 May-June and July-season end, disjoint windows. Select simplest candidate within one paired whole-game SE of the best pooled May-on log loss; reject a candidate clearly worse than baseline in either window. If no nonbaseline candidate qualifies, retain baseline. Freeze selection and code/input hashes before loading 2025 labels. All predeclared candidates may be replayed in previously inspected 2025 without changing the historical selection. This remains exploratory, not a new untouched holdout.

Metrics: matched-pitch all-take and supported-take log loss, Brier score, mean bias and calibration bins; paired whole-game bootstrap differences against both v4 and the no-umpire shared-region control (1,000 draws), region, handedness, count and monthly slices. Report coverage and unseen-group proportions. Proper scores, not raw umpire called-strike percentages, determine predictive value. Publish posterior umpire overall/region tendencies with opportunity counts and uncertainty, conditional on frozen base and estimated variance components.

Full-score guardrail: recompute q_take from the exact frozen RE288 ball/strike branches, preserve q_swing, reference and support, report factual take bias/RMSE/MSE intervals and preference/season-score sensitivity. Do not reuse old uncertainty intervals or claim counterfactual accuracy. Results are research artifacts; new season uncertainty propagation and external confirmation are still required before publishing final hitter grades.

Artifacts: data/raw/umpire_boxscores, data/models/umpire_v5, reports/umpire_v5. Scripts, manifests, coverage, prediction and model artifacts, tests, report and self-evaluation. No network writes, public posts or messages are involved.

Storage note before model comparison: the 2025 CSV is an evicted iCloud file. Its expected MD5 is pinned from the existing v4 input manifest. Historical fitting may proceed before hydration; the original CSV must materialize and match the pinned hash before the 2025 replay or completion. macOS download requests are limited to that existing project file.

Implementation repair: an audit detected that an initial numeric prediction column named umpire overwrote the umpire identifier. Those invalid model-run outputs are archived under discarded_column_collision; acquisition and feature caches are unaffected. Prediction columns are now umpire_model and umpire_region_model, actor identities are explicitly preserved, and all fits/predictive comparisons are rerun. No model specification was changed in response to predictive outcomes.

Numerical repair: default binomial optimization with extreme frozen offsets and added unpenalized region terms returned false convergence with coefficients of order 1e15. Native GAM prediction parity verified that this was fitting instability, not a prediction mismatch. Invalid outputs are archived under discarded_numerical_initialization. New candidates initialize eta at the existing base link; fitted training log loss must beat the nested offset/intercept model, coefficients must remain finite/nondivergent, and native mean/SE parity is verified. The model specifications and selection rule are unchanged.
